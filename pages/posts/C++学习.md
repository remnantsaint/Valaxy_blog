### C++ 计算机内存与数据类型

| 数据类型 | 常见大小 | 说明 |
| ---- | ---- | ---- |
| char | 1 Byte | 字符类型 |
| signed char | 1 Byte | 有符号字符 |
| unsigned char | 1 Byte | 无符号字符 |
| bool | 通常 1 Byte | 布尔类型 |
| short | 2 Byte | 短整型 |
| int | 4 Byte | 整型 |
| long | 4 或 8 Byte | 与平台有关 |
| long long | 8 Byte | 长整型 |
| float | 4 Byte | 单精度浮点数 |
| double | 8 Byte | 双精度浮点数 |
| long double | 8 或 16 Byte 等 | 与编译器和平台有关 |

  有符号数可以表示正数、负数和0，无符号数智能表示非负数，比如8位数，有符号就是 -2^7 ~ 2^7 - 1，无符号就是 0 ~ 2^8 - 1

  32位操作系统，指针通常是4B，64位是8B。 用 & 符号取地址。

  C++ 程序-> 使用虚拟地址 -> CPU/MMU -> 查询页表 -> 转换为物理地址 -> 访问实际物理内存。  虚拟内存可以：内存隔离、内存保护、内存管理、内存扩展机制。

  `sizeof()` 是 C++ 运算符，用来获取类型或者对象所占的存储空间大小，单位是 Byte。对于一个 arr[10] 的数组，sizeof(arr) 等于 40，因为十个元素，每个占4 B ，就是40字节。但是如果有 int *p = arr； 那么 sizeof(p) 就等于8，因为这个sizof() 计算指针变量本身的大小。

  对于 `char str[] = "hello"`，sizeof()的结果是 6，包括换行 \0，strlen 结果是5。
### C++ 指针与引用
  指针存储的内容是另一个变量的地址，指针本身也有地址。 & 取地址运算符、* 解引用运算符。

  通过指针修改对象，可以直接修改原变量，因为 *p 和 a 访问的是同一个对象。

  引用可以理解为一个变量的别名，int a = 10; 那么 int& r = a;，r 就是 a 的引用，修改r 就相当于 修改 a。

  指针和引用的区别：指针是存储地址的只针对想，可以为空，可以重新指向，访问对象需要解引用；引用是对象的别用，定义时必须初始化，需要绑定有效对象，不可以重新绑定，访问时可以直接使用。

  函数参数中指针和引用的区别：指针和引用是参数，都可以直接修改原变量。区别是指针传参可以表达空值，引用传参通常表达必须存在的对象，指针本身是按值传递的。如果希望函数修改外部指针的指向，可以使用二级指针或者指针引用。

  为什么函数参数经常使用 const 引用？ 1. 避免复制整个 string 对象及其管理的数据。2. const 保证函数不会通过该引用修改原对象。当传递一个很大的对象时，使用 const 引用可以减少不必要的拷贝。

  空指针表示没有指向有效对象的指针；野指针表示没有正确初始化或者指向不确定位置的指针；悬空指针表示原来指向一个有效对象，但生命周期结束后，指针仍然保留原来地址。

  返回局部变量的地址为什么危险？  因为局部变量的地址在函数结束后生命周期结束，返回的地址不再指向有效对象。

  `const int* p;`常量指针（指向常量的指针），可以修改指向，不能修改值。`int* const p;`指针常量，可以修改值，不能修改指向。`const int* const p`就都不能修改。

  二级指针就是保存一级指针的地址，比如 `int** pp = &p`，可以在函数中修改外部指针的指向，比如：
```c++
void change(int** pp) {
    static int b = 20;
    *pp = &b;
}
int main() {
    int a = 10;
    int* p = &a;
    change(&p);
    cout << *p << endl;
}
// 输出20
```
  `int **`和`int *&`都可以实现修改外部指针效果，但是语法和类型机制不同，前者是指向 `int*`的指针，后者是`int*`类型变量的引用。

  数组名会自动转换为指向数组首元素的指针，可以直接`int* p = arr;`等于`int* p = &arr[0]`。`sizeof(arr)`计算数组大小、`&arr`取整个数组地址，不会发生数组退化成指针。

  有代码如下：
```c++
int arr[5];
int* p = arr;
int (*q)[5] = &arr;
```
  p 是指向 int 的指针，q 是指向包含 5 个 int 的数组的指针。此时 p + 1 等于移动一个 int 的大小，而 q + 1 等于移动整个数组的大小。

  `int (*p)[4]`数组指针：p 是**指针**，指向长度 4 的 int 数组（行指针，适配二维数组），`int *p[4]`指针数组：p 是**数组**，里面每个元素是 int*（指针数组）。`int* p(int);`表示一个函数 p，接收一个 int 参数，返回一个 int*，叫做指针函数。

  比如有一个函数`int add(int a, int b);`，我们可以定义一个指针指向这个函数`int (*p)(int, int) = add`，这就是函数指针，含义是返回类型 int、参数类型int,int、p是指向符合上述函数类型的函数，用 p(10, 20) 这样调用。

  函数指针和指针函数区别：函数指针定义为`int (*p)(int)`，指针指向函数；指针函数定义为`int* p(int)`，函数返回指针。

  void 指针是一种通用对象指针，在不知道数据类型的情况下定义一个指针，不能直接解引用。用途最经典的是 C 语言中的 malloc。

  指针与引用的区别：  
1. 指针是独立变量，可以为 NULL，指向可以修改；引用是变量别名，定义时必须初始化，不能绑定空，绑定对象不能更换。
2. 指针会占用内存空间；引用不单独开辟内存。
3. 支持多级指针，不存在多级引用。
4. 访问方式：指针需要`*`解引用，引用直接使用。

  野指针是什么，如何避免：  
  野指针：指向非法内存、已经释放内存的指针，不等于 NULL。  
  避免方法：  
- 指针初始化时置为 NULL  
- free/delete 之后立刻把指针置 NULL  
- 不要返回局部栈变量的地址  
- 使用指针前先判断是否为空  

  数组指针和指针数组如何定义  
  数组指针（行指针）：`int (*p)[N]`，本质是指针，指向一个有 N 个 int 元素的数组。
指针数组：`int *p[N]`，本质是数组，数组里每一个元素都是 int * 指针。  

  函数指针和指针函数有什么区别  

指针函数：是函数，返回值为指针，写法 `int *func();`  
函数指针：是指针，用来存放函数地址，写法 `int (*func)(int);`，括号不能省略。   

  指针与数组的区别和联系  

联系：大部分场景下数组名会隐式转换成首元素地址，可以用指针方式访问数组元素。  
区别：数组是一段连续内存空间；数组名是地址常量，不能被赋值；指针是独立变量，可以修改指向，本身占用内存。  

  按值传递与按地址传递的区别  

按值传递：拷贝实参的副本，函数内部修改副本，不会影响外部原始变量。  
按地址传递：拷贝的是地址值，函数内通过地址修改指向的内存，外部原始变量会变化；本质上 C/C++ 里依然是值传递，传递的是地址这个值。  

### C++ 结构体与内存对齐
  结构体中可以包含多种数据类型，用 . 或者 -> 访问。

  struct 和 class 区别：主要区别是默认访问权限，struct默认权限都是 public，class 默认权限都是 private ，除此之外基本相同。

  内存对齐是：计算机在访问内存时，如果按照合适的边界埃列，通常可以更高效地访问。当需要对齐时，就要进行内存填充。

  每个成员起始地址，必须是自身大小的整数倍；结构体整体大小，必须是内部最大基础成员大小的整数倍。并且要看成员顺序，从上到下的看。

  union 和 struct 最大的区别是：struct 的成员分别拥有自己的存储空间，而 union 的所有成员共享同一块存储空间。sizeof(union) 等于最大成员的大小。
### C++ 内存管理
  C++ 程序的内存分区：

| 内存区域 | 主要存储内容 |
| ---- | ---- |
| 代码区（Text） | 程序的机器指令 |
| 常量区（常见为 rodata） | 字符串字面量、部分只读常量 |
| 全局/静态区（Data、BSS） | 全局变量、静态变量 |
| 堆区（Heap） | 动态申请的内存 |
| 栈区（Stack） | 函数调用过程中的局部变量、参数等 |

```c++
#include <iostream>
using namespace std;

int global = 10;        // 全局变量，全局/静态存储区

int main() {
    int a = 20;         // 局部变量，栈

    static int b = 30;  // 静态局部变量，全局/静态存储区

    int* p = new int(40); // 动态分配的对象，p 是一个局部指针变量，通常在栈上，new int(40) 创建的对象在动态存储区，通常称为堆。

    cout << global << endl;
    cout << a << endl;
    cout << b << endl;
    cout << *p << endl;

    delete p;
}
```
  Data 和 BSS 区别：Data 通常存放已经初始化且需要保留初始值的全局、静态变量，BSS 通常存放未显式初始化或零初始化的全局、静态变量。

  栈是一种自动管理生命周期的内存区域，主要存函数调用过程中（包括主函数）的局部变量、参数等。堆主要用于动态内存分配。栈的堆的区别：

| 对比 | 栈 Stack | 堆 Heap |
| ---- | ---- | ---- |
| 管理方式 | 自动管理 | 动态分配和释放 |
| 生命周期 | 通常跟随作用域/调用 | 由对象生命周期和所有权决定 |
| 分配速度 | 通常较快 | 通常有额外管理开销 |
| 空间 | 通常比较有限 | 通常相对更大 |
| 典型用途 | 局部变量、函数调用 | 动态对象、动态，吗数组 |
| 常见问题 | 栈溢出 | 内存泄漏、碎片等 |

  栈空间通常比较有限，函数调用和局部变量会使用栈空间。如果递归层数过深，或者局部变量占用空间过大，就可能导致栈溢出。

  new 用于创建动态对象，delete 用于销毁通过 new 创建的动态对象。new 不只是申请内存，还负责对象的初始化；delete 不只是释放内存，还负责对象的销毁。new 会调用构造函数，delete 会调用析构函数。

  malloc 是 C 语言提供的动态内存分配函数，需要手动指定申请的字节数，不会自动调用构造函数，free 不会自动调用析构函数。malloc 可以在 C++ 中分配动态内存。

  内存泄漏：程序申请了内存，但不再需要这块内存时，没有正确释放，导致内存无法正常回收。

  智能指针本质上是一个管理资源生命周期的对象。利用 RALL 思想：把资源的生命周期与对象的生命周期绑定起来，在对象销毁时自动释放资源。unique_ptr：独占所有权、shared_ptr：共享所有权、weak_ptr：弱引用。

  unique_ptr 用于独占资源，适合只有一个对象负责管理资源，shared_ptr 通过引用计数实现共享所有权，适合多个对象共同管理资源，weak_ptr 不增加强引用计数，通常用于观察对象和解决 shared_ptr 循环引用问题。

  一个对象从构造到析构，内存是怎么走的？对象创建时，首先需要获得存储空间，然后调用构造函数进行初始化。对象销毁时，先执行析构函数，再释放对应的存储空间。普通局部对象一般在离开作用域时自动析构，而通过 new 创建的动态对象通常需要通过 delete 销毁，也可以交给智能指针管理。

  如何避免内存泄漏？1.使用 new 后正确使用 delete，使用 malloc 后正确使用 free。2.优先使用智能指针管理动态对象。3.使用 RAII 思想，让资源跟随对象生命周期自动释放。4.避免 shared_ptr 循环引用，需要时使用 weak_ptr。5.使用 AddressSanitizer、Valgrind 等工具检测内存问题。

  智能指针如何管理内存？unique_ptr： 独占资源，智能指针销毁时自动释放所管理的对象；shared_ptr： 多个智能指针共同管理资源，通过强引用计数记录所有者数量，最后一个所有者释放时销毁对象；weak_ptr： 不增加强引用计数，不负责延长对象生命周期。需要访问对象时通过 lock 获取临时 shared_ptr。
### C++ 类与对象
  public：类外可以访问；private：只能由类自身及友元等访问；protected：类自身及派生类等可以访问。

  封装：将数据和操作封装在类中，控制外部访问；继承：子类可以服用和扩展父类功能；多态：同一接口根据对象实际类型表现出不同行为。

  构造函数是在对象创建时用于初始化对象的特殊成员函数，会在创建对象时自动执行。析构函数用于对象生命周期结束时执行清理工作，在对象销毁时自动调用。

  对于同一作用域中依次创建的普通局部对象，通常先构造的后析构，后构造的先析构。

  构造函数不能是虚函数，因为构造过程中，对象还没有完成其完整类型的初始化，虚函数调用机制不能像普通运行期多态那样应用于构造函数。但析构函数可以是虚函数，如果一个类要作为多态基类，并且可能通过基类指针删除派生类对象，通常应该把基类析构函数声明为 virtual。

  已有一个对象 s1，用 s1 初始化 s2 的话，就可能调用拷贝构造函数，一般是`Student(const Student& other);`。拷贝构造是在创建新对象时使用已有对象初始化它，而拷贝赋值是对已经存在的对象进行赋值。

  浅拷贝通常指直接复制对象的各个成员，可能共享资源，开销小，如果类中有指针成员，复制后两个指针可能指向同一块内存，从而发生重复释放等问题。深拷贝指复制对象时，如果它管理着需要独立拥有的动态资源，就为新对象创建独立资源，再复制资源内容。

  static 成员变量属于类，由同一个类的所有对象共享。普通成员变量属于每一个对象。

  static 成员函数不需要创建对象就可以调用。

  const 成员函数表示不修改对象的普通成员状态，常用于只读操作。

  空类的 sizeof 是 1 字节。

  static 关键字有什么作用？1. 在函数内部修饰局部变量，变量具有静态存储期，只初始化一次，生命周期持续到程序结束阶段。2. 在类中修饰成员变量，该变量属于类，由所有对象共享。3. 在类中修饰成员函数，可以通过类名调用，函数没有 this 指针。4. 在命名空间作用域修饰变量或函数，通常表示内部链接，使名称只在当前翻译单元内可见。
### C++ 继承、多态与虚函数
  继承允许一个类在已有类的基础上增加或修改功能。子类对象可以赋值给父类指针，比如`Animal* p = new Dog();`，但是反过来不行，因为Animal 不一定具备 Dog 的成员和行为。

  重载：函数名相同但参数不同。重写：指派生类重新实现基类的虚函数，一般用 override 关键字。隐藏：派生类声明了与基类同名的成员，会隐藏基类功能。

  多态是 相同的函数调用形式，面对不同类型的对象，表现出不同的行为。静态多态可以是重载，动态多态允许程序在运行时，根据对象的实际类型决定调用哪个函数。

  动态多态的条件：存在基类和派生类关系；基类声明虚函数；派生类重写虚函数；通过基类指针或引用调用这个虚函数。

  没有 virtual 时，`p->speak()`通常在编译阶段就根据 p 的静态类型 Animal* 确定调用 Animal* 的 speak()，加上 virtual 后，基类声明了虚函数，派生类重写了它，所以通过基类指针进行虚调用时，程序会根据对象的实际类型选择对应的函数。

  virtual 说明基类成员函数是虚函数，override 说明派生类函数要重写一个虚函数，编译器会检查是否成功重写。

  虚函数表是主流 C++ 编译器实现动态多态的常见机制，但 C++ 标准没有强制规定一定要采用这种实现。

  虚函数表可以理解成一张函数地址表，编译器会为一个多态类构建相应的虚函数表，虚函数表负责提供动态调用时需要查找的函数入口。虚表指针是对象中由编译器维护、指向虚函数表的隐藏指针。

  虚表本身通常存储在程序的只读数据区域。虚表通常与类型对应，同类对象共享虚表信息；而虚表指针存在于对象内部，用来定位相应的虚表。

  虚函数通过虚表实现动态多态的基本过程：1. p 指向一个 Dog 对象。2. 程序访问该对象中的 vptr。3. 根据 vptr 找到对应的虚函数表。4. 找到 speak 对应的函数入口。5. 调用 Dog::speak()。

  普通虚函数有自己的实现，而纯虚函数使用 `= 0` 声明。包含至少一个尚未被实现的纯虚函数的类，就是抽象类。

  纯虚函数用于定义统一接口，让不同派生类实现自己的行为。

|对比|虚函数|纯虚函数|
| ---- | ---- | ---- |
|声明|virtual void f()|virtual void f() = 0|
|是否可以有实现|可以|也可以在类外提供定义|
|是否强制派生类实现|不强制|具体派生类必须完成最终实现|
|类是否一定抽象|不一定|存在未实现纯虚函数时是抽象类|

  析构函数一般是虚函数，因为只调用基类析构函数，子类资源无法正确释放。会先调用子类析构，再调用父类析构。构造从基类到派生类，析构从派生类到基类。

  如果一个类不需要通过基类指针进行多态删除，就不一定需要虚析构函数。

  静态绑定通常在编译阶段确定函数调用，例如普通非虚函数调用、函数重载。动态绑定则在运行时根据对象的实际类型选择函数，C++ 中主要通过虚函数实现。
### C++ 进阶特性与编译链接
  const 声明只读，限制修改。static 静态存储和类共享成员。static 函数内部的静态局部变量：只初始化一次，不随着函数返回而销毁；类的静态成员变量，所有对象共享一个 statics 静态成员变量；类的静态成员函数，不依赖具体对象，没有 this 指针。

  constexpr 要求变量的初始化满足编译期常量表达式要求。constexpr 对象也具有 const 性质，但普通 const 对象不一定是编译期常量。

  int a = 10; 其中表达式 a 就是一个左值，表达式 10 就是右值。左值通常有明确身份，能够持续定位。右值通常表示临时结果，或者可以被当作即将被移动资源的表达式。

  左值引用：`int& r = a`，但是右侧不能直接是常量，因为普通的非 const 左值引用不能直接绑定普通右值，但是加上 const 就可以。右值引用是`int&& r = 10;`右侧不能是 a，因为 a 是左值，而普通右值引用不能直接绑定左值。

  右值引用主要是为了支持：移动语义、完美转发。帮助程序识别 资源可能可以转移，而不必复制。转移动态资源的所有权，避免完整复制所有元素。

  std::move 就是移动，但是本身不会移动数据，它把表达式转换为允许进行移动处理的右值形式，通常是 xvalue，真正的资源移动发生在后续被调用的移动构造函数或移动赋值运算符中。

  移动后的原对象仍是有效对象，但状态通常未指定。std::move 主要用于把表达式转换为可被移动的右值形式，而 std::forward 通常用于模板中的完美转发，在满足转发引用推导规则时保留参数原本的左值或右值属性。

  volatile 用于告诉编译器：对象的值可能受到普通程序控制之外的因素影响，因此对 volatile 对象的访问不能简单地按照普通对象的优化方式省略或合并。volatile 不保证线程安全，也不保证原子性。volatile只阻止编译器优化、保证每次从内存读取

  静态链接是指在链接阶段，将程序需要的静态库相关代码合并进最终链接产物。动态链接是让程序依赖单独存在的共享库文件。
