### C++ 计算机内存与数据类型

| 数据类型 | 常见大小 | 说明 |
| ---- | ---- | ---- |
| char | 1 Byte | 字符类型 |
| signed char | 1 Byte | 有符号字符 |
| unsigned char | 1 Byte | 无符号字符 |
| bool | 通常 1 Byte | 布尔类型 |
| short | 2 Byte | 短整型 |
| int | 4 Byte | 整型 |
| long | 4 或 8 Byte | 与平台有关 |
| long long | 8 Byte | 长整型 |
| float | 4 Byte | 单精度浮点数 |
| double | 8 Byte | 双精度浮点数 |
| long double | 8 或 16 Byte 等 | 与编译器和平台有关 |

  有符号数可以表示正数、负数和0，无符号数智能表示非负数，比如8位数，有符号就是 -2^7 ~ 2^7 - 1，无符号就是 0 ~ 2^8 - 1
  
  32位操作系统，指针通常是4B，64位是8B。 用 & 符号取地址。
  
  C++ 程序-> 使用虚拟地址 -> CPU/MMU -> 查询页表 -> 转换为物理地址 -> 访问实际物理内存。  虚拟内存可以：内存隔离、内存保护、内存管理、内存扩展机制。
  
  `sizeof()` 是 C++ 运算符，用来获取类型或者对象所占的存储空间大小，单位是 Byte。对于一个 arr[10] 的数组，sizeof(arr) 等于 40，因为十个元素，每个占4 B ，就是40字节。但是如果有 int *p = arr； 那么 sizeof(p) 就等于8，因为这个sizof() 计算指针变量本身的大小。
  
  对于 `char str[] = "hello"`，sizeof()的结果是 6，包括换行 \0，strlen 结果是5。
### C++ 指针与引用
  指针存储的内容是另一个变量的地址，指针本身也有地址。 & 取地址运算符、* 解引用运算符。
  
  通过指针修改对象，可以直接修改原变量，因为 *p 和 a 访问的是同一个对象。
  
  引用可以理解为一个变量的别名，int a = 10; 那么 int& r = a;，r 就是 a 的引用，修改r 就相当于 修改 a。
  
  指针和引用的区别：指针是存储地址的只针对想，可以为空，可以重新指向，访问对象需要解引用；引用是对象的别用，定义时必须初始化，需要绑定有效对象，不可以重新绑定，访问时可以直接使用。
  
  函数参数中指针和引用的区别：指针和引用是参数，都可以直接修改原变量。区别是指针传参可以表达空值，引用传参通常表达必须存在的对象，指针本身是按值传递的。如果希望函数修改外部指针的指向，可以使用二级指针或者指针引用。
  
  为什么函数参数经常使用 const 引用？ 1. 避免复制整个 string 对象及其管理的数据。2. const 保证函数不会通过该引用修改原对象。当传递一个很大的对象时，使用 const 引用可以减少不必要的拷贝。
  
  空指针表示没有指向有效对象的指针；野指针表示没有正确初始化或者指向不确定位置的指针；悬空指针表示原来指向一个有效对象，但生命周期结束后，指针仍然保留原来地址。
  
  返回局部变量的地址为什么危险？  因为局部变量的地址在函数结束后生命周期结束，返回的地址不再指向有效对象。
  
  `const int* p;`指针常量（指向常量的指针），可以修改指向，不能修改值。`int* const p;`常量指针，可以修改值，不能修改指向。`const int* const p`就都不能修改。
  
  二级指针就是保存一级指针的地址，比如 `int** pp = &p`，可以在函数中修改外部指针的指向，比如：
```c++
void change(int** pp) {
    static int b = 20;
    *pp = &b;
}
int main() {
    int a = 10;
    int* p = &a;
    change(&p);
    cout << *p << endl;
}
// 输出20
```
  `int **`和`int *&`都可以实现修改外部指针效果，但是语法和类型机制不同，前者是指向 `int*`的指针，后者是`int*`类型变量的引用。
  
  数组名会自动转换为指向数组首元素的指针，可以直接`int* p = arr;`等于`int* p = &arr[0]`。`sizeof(arr)`计算数组大小、`&arr`取整个数组地址，不会发生数组退化成指针。
  
  有代码如下：
```c++
int arr[5];
int* p = arr;
int (*q)[5] = &arr;
```
  p 是指向 int 的指针，q 是指向包含 5 个 int 的数组的指针。此时 p + 1 等于移动一个 int 的大小，而 q + 1 等于移动整个数组的大小。
  
  `int (*p)[4]`数组指针：p 是**指针**，指向长度 4 的 int 数组（行指针，适配二维数组），`int *p[4]`指针数组：p 是**数组**，里面每个元素是 int*（指针数组）。`int* p(int);`表示一个函数 p，接收一个 int 参数，返回一个 int*，叫做指针函数。
  
  比如有一个函数`int add(int a, int b);`，我们可以定义一个指针指向这个函数`int (*p)(int, int) = add`，这就是函数指针，含义是返回类型 int、参数类型int,int、p是指向符合上述函数类型的函数，用 p(10, 20) 这样调用。
  
  函数指针和指针函数区别：函数指针定义为`int (*p)(int)`，指针指向函数；指针函数定义为`int* p(int)`，函数返回指针。
  
  void 指针是一种通用对象指针，在不知道数据类型的情况下定义一个指针，不能直接解引用。用途最经典的是 C 语言中的 malloc。
  
  指针与引用的区别：  
1. 指针是独立变量，可以为 NULL，指向可以修改；引用是变量别名，定义时必须初始化，不能绑定空，绑定对象不能更换。
2. 指针会占用内存空间；引用不单独开辟内存。
3. 支持多级指针，不存在多级引用。
4. 访问方式：指针需要`*`解引用，引用直接使用。

  野指针是什么，如何避免：  
  野指针：指向非法内存、已经释放内存的指针，不等于 NULL。  
  避免方法：  
- 指针初始化时置为 NULL  
- free/delete 之后立刻把指针置 NULL  
- 不要返回局部栈变量的地址  
- 使用指针前先判断是否为空  

  数组指针和指针数组如何定义  
  数组指针（行指针）：`int (*p)[N]`，本质是指针，指向一个有 N 个 int 元素的数组。
指针数组：`int *p[N]`，本质是数组，数组里每一个元素都是 int * 指针。  

  函数指针和指针函数有什么区别  

指针函数：是函数，返回值为指针，写法 `int *func();`  
函数指针：是指针，用来存放函数地址，写法 `int (*func)(int);`，括号不能省略。   

  指针与数组的区别和联系  

联系：大部分场景下数组名会隐式转换成首元素地址，可以用指针方式访问数组元素。  
区别：数组是一段连续内存空间；数组名是地址常量，不能被赋值；指针是独立变量，可以修改指向，本身占用内存。  

  按值传递与按地址传递的区别  

按值传递：拷贝实参的副本，函数内部修改副本，不会影响外部原始变量。  
按地址传递：拷贝的是地址值，函数内通过地址修改指向的内存，外部原始变量会变化；本质上 C/C++ 里依然是值传递，传递的是地址这个值。  

### C++ 结构体与内存对齐
  结构体中可以包含多种数据类型，用 . 或者 -> 访问。
  
  struct 和 class 区别：主要区别是默认访问权限，struct默认权限都是 public，class 默认权限都是 private ，除此之外基本相同。
  
  内存对齐是：计算机在访问内存时，如果按照合适的边界埃列，通常可以更高效地访问。当需要对齐时，就要进行内存填充。
  
  每个成员起始地址，必须是自身大小的整数倍；结构体整体大小，必须是内部最大基础成员大小的整数倍。并且要看成员顺序，从上到下的看。
  
  union 和 struct 最大的区别是：struct 的成员分别拥有自己的存储空间，而 union 的所有成员共享同一块存储空间。sizeof(union) 等于最大成员的大小。
### C++ 内存管理
  C++ 程序的内存分区：

| 内存区域 | 主要存储内容 |
| ---- | ---- |
| 代码区（Text） | 程序的机器指令 |
| 常量区（常见为 rodata） | 字符串字面量、部分只读常量 |
| 全局/静态区（Data、BSS） | 全局变量、静态变量 |
| 堆区（Heap） | 动态申请的内存 |
| 栈区（Stack） | 函数调用过程中的局部变量、参数等 |
  
```c++
#include <iostream>
using namespace std;

int global = 10;        // 全局变量，全局/静态存储区

int main() {
    int a = 20;         // 局部变量，栈

    static int b = 30;  // 静态局部变量，全局/静态存储区

    int* p = new int(40); // 动态分配的对象，p 是一个局部指针变量，通常在栈上，new int(40) 创建的对象在动态存储区，通常称为堆。

    cout << global << endl;
    cout << a << endl;
    cout << b << endl;
    cout << *p << endl;

    delete p;
}
```
  Data 和 BSS 区别：Data 通常存放已经初始化且需要保留初始值的全局、静态变量，BSS 通常存放未显式初始化或零初始化的全局、静态变量。
  
  栈是一种自动管理生命周期的内存区域，主要存函数调用过程中（包括主函数）的局部变量、参数等。堆主要用于动态内存分配。栈的堆的区别：

| 对比 | 栈 Stack | 堆 Heap |
| ---- | ---- | ---- |
| 管理方式 | 自动管理 | 动态分配和释放 |
| 生命周期 | 通常跟随作用域/调用 | 由对象生命周期和所有权决定 |
| 分配速度 | 通常较快 | 通常有额外管理开销 |
| 空间 | 通常比较有限 | 通常相对更大 |
| 典型用途 | 局部变量、函数调用 | 动态对象、动态数组 |
| 常见问题 | 栈溢出 | 内存泄漏、碎片等 |
